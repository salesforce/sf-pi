# AGENTS.md — sf-data360

Repository rules still apply. This extension exposes exactly one Pi system tool: `sf_data360`.

## Read first

1. `index.ts` — extension and command registration.
2. `lib/sf-data360-tool.ts` — the only Pi tool schema and lifecycle adapter.
3. `lib/sdk.ts` — public action execution seam.
4. `lib/actions/action-registry.ts` — generated business action lookup and routing.
5. `lib/actions/dispatcher.ts` — local, journey, and endpoint dispatch.
6. `lib/operation-executor.ts` — thin generated Connect API executor.
7. `lib/digest.ts`, `lib/presentation-data.ts`, `lib/render.ts`, and `lib/orchestration-diagram.ts` — model/human result projections.
8. `lib/query-v3.ts` and `lib/actions/ingest/` — direct data-plane transports.
9. The matching focused Behavior Proof.

## Contracts

- Public actions start with `discover`, `connect`, `prepare`, `harmonize`, `segment`, `activate`, `query`, `semantic`, `observe`, `orchestrate`, or `api`.
- `registry/actions.json` is generated by `scripts/generate-d360-actions.mjs`.
- `registry/connect-openapi-contracts.json` is a normalized snapshot of the official Data 360 Connect OpenAPI document; `connect-openapi-parity.json` compares it with endpoint-backed SDK actions, and `connect-openapi-overrides.json` records reviewed adapter/live-shape differences.
- Known upstream endpoint operations map to exactly one primary action or one canonical action alias.
- `discover.action.describe` exposes endpoint, safety, required/optional parameters, and examples on demand.
- `api.request` is an exact endpoint escape hatch, never an arbitrary-host HTTP client.
- No endpoint-specific Pi tools, MCP/Java runtime, raw CLI transport, legacy generic-card layer, facade, or compatibility registration is allowed. Human Run Cards must derive from the stable digest and remain independent of execution.
- Mutations require dry-run review, `allow_mutation: true`, and Guardrail mediation.
- Keep model content compact; render full API URLs, SQL, bounded payloads, and domain tables through the human Run Card. Persist artifacts only for broad, diagnostic, orchestrated, or mutating evidence.
